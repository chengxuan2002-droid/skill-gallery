# Contract: 详情、内容标识与稳定分享

**Feature**: US-002 | **Date**: 2026-11-05 | **Related**: [spec.md](../spec.md)、[data-model.md](../data-model.md)

## 1. 范围

本契约约束详情页的公开行为：信息分区、版本/内容标识、原文安全展示、复制、下载、分享地址和失败状态。
详情数据仍来自既有 `details/<slug>.json` 与 `schemaVersion=1`，不新增字段或迁移。

## 2. 详情路由

- 详情地址固定为 `#/skill/<slug>`；slug 使用标准 URL 编码。
- 旧 `#/skill/<slug>` 链接、刷新和同 slug 内容更新后必须继续打开同一 Skill 的当前内容。
- 详情地址 MUST NOT 附加列表查询参数；列表返回位置只保存在当前会话。
- 未知 slug 显示 `not_found`，提供返回列表；不得展示其他 Skill。

## 3. 字段映射

| 展示区 | 来源字段 | 规则 |
|---|---|---|
| 名称 | `display_name` | 缺失回退 slug |
| 功能简介 | `description` | 缺失“未提供” |
| 适用场景与使用方法 | `usage` | 站点说明区；缺失“未提供” |
| 备注 | `notes` | 站点说明区；缺失可隐藏 |
| 标签/平台 | `tags` / `platforms` | 纯文本徽标；可为空 |
| 声明版本 | `declared_version` | 存在时显示；不要求 SemVer |
| 内容标识 | `digest` 前 12 位 | 声明版本缺失时作为内容身份；与声明版本分开标注 |
| 作者 | `author` | 缺失“未提供” |
| 来源类型 | `source_type` | 缺失“未提供” |
| 官方主页 | `homepage_url` | 仅 http/https；缺失“未提供” |
| 开源地址 | `repository_url` | 仅 http/https；缺失“未提供” |
| 许可 | `license` | 缺失“未提供” |
| 更新时间 | `updated_at` | 站内记录最近实质更新时间；缺失“未提供”；不使用检查/构建时间 |
| 原文 | `body_html` | 仅已清理 HTML；不从 `content_text` 重建 |
| 附件 | `files` / `directories` | 路径、大小、可执行位；合法性由 US-001 校验 |
| 下载入口 | `download_url` / `download_name` | 单文件原名；目录 ZIP；不得从检索文本重建 |

站点说明、站内标签/备注与上游原文 MUST 分区展示；不得把站内说明混入 `body_html`，也不得用检索文本
覆盖原文。

## 4. 版本与内容身份

- 声明版本存在时显示版本；它是上游声明，不保证 SemVer，也不等同内容变化。
- 声明版本缺失时显示 `digest` 前 12 位作为“内容标识”；若 `digest` 不可用，显示“未提供”并报告数据缺口。
- 不得因版本未变就声称内容未变；内容更新由快照 `contentRevision`/`digest` 校验。
- 版本、内容标识、更新时间和来源地址分别展示，避免混为同一字段。

## 5. 操作契约

| 操作 | 成功 | 失败 |
|---|---|---|
| 查看原文 | 从 `raw_url` 读取并校验大小/摘要，按严格 UTF-8 显示 | `raw_unavailable`，不展示错误页为原文 |
| 复制原文 | 等待剪贴板真实成功后提示 | `copy_failed`，保留可手动复制的原文 |
| 下载原件/目录包/附件 | 校验响应/大小/摘要后按原名下载 | `download_failed`，不提示成功、不保存错误页 |
| 复制详情分享链接 | 复制 `#/skill/<slug>` 规范地址并提示成功 | `copy_failed`，显示可手动复制的地址 |
| 复制列表分享链接 | 复制当前列表地址（含查询/筛选/排序）并提示成功 | `copy_failed`，显示可手动复制的地址 |
| 返回列表 | 恢复进入详情前的列表地址；无记录时回列表根 | 不改变 Skill 身份 |

US-001 已验收的原文复制、原件/ZIP 下载、旧链接和当前单版本 MUST 继续可用；本故事不得用检索文本
或清理后的展示 HTML 替代原件下载。

## 6. 分享地址

- 详情：当前文档目录作为基址，去掉 Hash 后拼接 `#/skill/<slug>`；保持 `/skill-gallery/` 子路径。
- 列表：当前列表 Hash 本身，包含查询、模式、筛选和排序；空条件可回到 `#/`。
- 所有分享地址 MUST NOT 包含凭证、管理信息、内部路径或编辑器状态。
- 复制成功只在真实剪贴板写入成功后提示；拒绝时提供可手动选择的完整地址。
- 同 slug 内容更新后旧地址仍指向新版；不提供旧版本选择入口。

## 7. 安全与错误状态

- `body_html` 只使用构建阶段已清理的 HTML；其他字段使用文本/安全属性插入，禁止未清理 Markdown
  直接进入 `innerHTML`。
- 原文中的活动 HTML/脚本/事件属性不得执行；外链仅允许 http/https；相对引用只映射当前 Skill 已发布文件。
- 缺失或越界相对引用显示可见错误/不可用状态，不暗中展示其他 Skill 或项目文件。
- 未知 slug：`not_found`；请求/解析失败：`load_failed` 可重试；
  索引/详情快照不一致：`snapshot_mismatch` 提示刷新；不显示空库或错误内容。
- 复制/下载失败状态独立于详情主体，可恢复且不误报成功。
