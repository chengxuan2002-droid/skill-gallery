## User Scenarios & Testing *(mandatory)*

### User Story 1 - 快速找到并筛选 Skill（US-002.A，Priority: P1）

作为访客，我希望用中文或英文关键词、精准或模糊模式找到 Skill，并按标签、平台、来源和作者组合筛选，
以便从个人收藏中快速定位真正需要的内容，而不是逐张卡片浏览。

**Why this priority**: 检索是站点最直接的使用价值；没有可靠的多维检索，详情、分享和视觉改版都无法形成可用闭环。

**Independent Test**: 使用包含中英文名称、简介、用法、标签、平台、作者和来源的隔离样例库，
仅通过查询、模式切换、筛选、排序和分享地址验证结果，不依赖正式四项数据或生产站点。

**Acceptance Scenarios**:

1. **Given** 名称含 `debugging`、中文用法含“文档转换”的样例及多标签数据，
   **When** 访客用精准模式搜索 `debug`、用双引号搜索完整短语、用模糊模式搜索 `debuging`，
   **Then** 精准模式按规范化连续片段命中且不自动纠错，模糊模式容忍英文轻微拼写误差，
   中文至少按连续子串命中，不承诺中文语义近义词。对应 FR-002、AC-003。
2. **Given** 同一维度有多个标签或多个平台，**When** 访客同时选择多个标签或平台，
   **Then** 同维度结果为 OR；再叠加作者或来源条件时，不同维度为 AND，结果不重复。
   对应 FR-002、AC-003。
3. **Given** 有关键词或无关键词，**When** 访客不显式排序或显式选择名称/更新时间排序，
   **Then** 有关键词默认按相关度，用户显式排序被尊重；无关键词默认最近更新；同分以 slug 稳定排序。
   对应 FR-002、AC-003。
4. **Given** 查询、模式、筛选和排序条件，**When** 访客复制或重新打开当前地址，
   **Then** 结果、命中数、模式和条件从地址恢复；地址只包含可公开的查询与筛选值，不含凭证。
   对应 FR-002、AC-003、AC-005 的分享部分。
5. **Given** 组合查询、空结果、空库或加载失败，**When** 访客查看结果区，
   **Then** 分别显示命中数、当前条件、清除入口或可恢复错误，不把加载失败伪装成空库。
   对应 FR-002、FR-010。
6. **Given** 已发布的检索数据可用，**When** 访客输入查询，
   **Then** 名称命中优先于说明/标签，说明/标签优先于正文，结果在一次查询内去重且与筛选条件一致。
   对应 FR-002、NFR-002。

### User Story 2 - 完整理解并稳定分享一个 Skill（US-002.B，Priority: P1）

作为访客，我希望在详情中先看到名称、简介、版本/内容标识、作者、来源和操作入口，再阅读用法、
站点说明与上游原文，并能复制稳定链接分享给他人，以便判断这个 Skill 是否适合自己且不会分享错误内容。

**Why this priority**: 检索只是找到内容；只有详情信息完整、缺失状态诚实、分享链接稳定，访客才能完成查阅与分享。

**Independent Test**: 使用信息齐全和作者/版本缺失的隔离样例，检查详情分区、缺失提示、
原文安全展示、旧链接、分享复制成功/失败及未知 slug 状态，不依赖上传、自动更新或生产发布。

**Acceptance Scenarios**:

1. **Given** 信息齐全及作者/版本缺失的两项，**When** 访客打开详情，
   **Then** 展示功能简介、适用场景、使用方法、原文、版本或内容标识、作者、官方地址、开源地址和更新时间；
   缺失项明确显示“未提供”，不编造作者、地址或 SemVer。对应 FR-003、AC-004。
2. **Given** 站点说明与上游原文存在差异，**When** 访客阅读详情，
   **Then** 站点说明、站内备注/标签与上游原文分区展示，原文中的代码块、表格、列表和相对附件链接可读，
   不把站内说明混入原件，也不从检索文本重建原文。对应 FR-003、AC-004；
   原件保真回归由 US-001 的 AC-002 承担。
3. **Given** 原文未声明版本，**When** 访客查看版本区域，
   **Then** 展示当前内容的来源短修订或内容标识；声明版本与内容身份不混为一谈，
   不因版本未变就声称内容未变。对应 FR-003、AC-004。
4. **Given** 原文含活动 HTML、事件属性或危险地址，另有合法附件，**When** 访客查看详情，
   **Then** 页面不执行活动内容，外部地址仅允许安全协议，相对引用只指向当前 Skill 的已发布文件；
   合法附件仍可按 US-001 的保真方式取用。对应 FR-003、AC-012。
5. **Given** 既有 `#/skill/<slug>` 链接、刷新或同 slug 内容更新，**When** 访客重新打开链接，
   **Then** 同一 Skill 身份保持，读取当前版本，不跳到其他 Skill；未知 slug 显示可返回列表的未找到状态。
   对应 FR-004、AC-005。
6. **Given** 详情链接或带查询条件的列表地址，**When** 访客复制分享链接、剪贴板拒绝或链接不可用，
   **Then** 复制成功只在真实成功后提示；失败明确提示并保留可手动复制的文本；
   带查询条件的地址可恢复同一查询/筛选/排序结果。对应 FR-004、AC-005。

### User Story 3 - 在多种设备与主题下无障碍使用（US-002.C，Priority: P2）

作为使用桌面、平板或手机的访客，我希望在窄屏、明暗主题和纯键盘操作下仍能完成搜索、筛选、
详情、下载和分享，文字与焦点清晰可辨，以便不因设备或输入方式被排除在主要流程之外。

**Why this priority**: 视觉改版只有在不牺牲可访问性和基本操作时才有价值；它低于检索与详情，但属于本轮验收范围。

**Independent Test**: 在 360、768、1440px 宽度、明暗主题、纯键盘和减少动效偏好下完成主要流程，
记录浏览器版本、焦点顺序、对比度和溢出结果；不依赖上传、自动更新或生产发布。

**Acceptance Scenarios**:

1. **Given** 360、768、1440px 宽度，**When** 访客浏览列表和详情，
   **Then** 移动端为单列卡片且筛选可展开收起，桌面端筛选与结果分栏；
   正文外无横向溢出，代码块内部可横向滚动。对应 FR-010、NFR-005、AC-013。
2. **Given** 只用键盘，**When** 访客搜索、切换模式、选择筛选、排序、打开详情、下载和复制分享链接，
   **Then** 所有主要操作可达，焦点可见，表单有标签，操作使用真实按钮或链接。
   对应 FR-010、NFR-005、AC-013。
3. **Given** 明暗主题、正文对比度和减少动效偏好，**When** 访客切换主题或使用系统偏好，
   **Then** 正文对比至少 4.5:1，焦点指示清晰，减少动效偏好生效，
   不使用粒子背景、自动播放视频或大面积霓虹干扰阅读。对应 FR-010、NFR-005、AC-013。
4. **Given** 当前稳定的 Chromium、Firefox 和 WebKit，**When** 执行主要流程，
   **Then** 结果和状态一致；未运行或失败的浏览器单独记录，不以单一浏览器结果宣称全部通过。
   对应 NFR-005、AC-013。

### Edge Cases

- 空查询、纯空白、未闭合双引号、单字符查询、超长查询和中英文混合查询：给出确定结果或明确空结果，不崩溃。
- 无标签、无平台、无作者、无声明版本、无官方地址、无开源地址或无更新时间：显示“未提供”，不编造。
- Skill 缺少被筛选的作者、来源、标签或平台值：不匹配该筛选条件，清除条件后重新出现；不把缺失值当通配。
- 同名或同分 Skill：按 slug 稳定排序，结果不重复、不跳项。
- 空库、无结果、未知 slug、详情不可用或内容快照已更新：显示可区分状态及返回/重试，不显示其他 Skill。
- 地址参数非法、未知筛选值或编码异常：安全忽略或回到可用状态，不执行任意内容、不泄露内部信息。
- 剪贴板不可用或被拒绝：明确失败并保留手动复制方式，不显示成功提示。
- 移动端筛选展开/收起、浏览器前进后退和刷新：条件与结果保持一致，不丢失当前 Skill 身份。
- 代码块、表格、长标题和长 URL：正文外不横向溢出；外部链接仅使用安全协议。
- 原文相对链接缺失或越界：显示可见错误或不可用状态，不暗中展示其他 Skill 或项目文件。
- 同 slug 内容替换后旧链接：继续打开同一 Skill 的当前版本，不提供旧版本选择入口。
- 数据规模达到 1,000 项、总正文 10 MiB：查询仍可用，并按要求记录性能结果；四项数据不能替代该测量。
- 当前浏览器或测试设备不可用：按未运行记录，不把未运行写成通过。

## Requirements *(mandatory)*

### Functional Requirements

以下沿用上游 FR 编号，仅细化 US-002 切片；未列出的上游完整功能不因此被隐式纳入。

- **FR-002（本轮）**：访客 MUST 能按名称、简介、标签、平台、来源类型、作者、用途、使用说明和正文检索，
  无关键词时可浏览全部。MUST 提供显式精准/模糊模式，默认模糊；精准模式对规范化文本做连续片段匹配，
  双引号表达完整短语，大小写与空白归一且不自动纠错；模糊模式允许英文轻微拼写误差，
  中文至少支持连续子串，不承诺中文语义近义词。MUST 支持同维度多选 OR、跨维度 AND；
  MUST 支持相关度默认排序及用户显式名称/更新时间排序；相关度应优先名称命中，其次说明/标签，再次正文；
  无关键词且未显式选择排序时默认最近更新，同分按 slug 稳定排序。
  结果 MUST 显示命中数、当前条件和清除入口；查询、模式、筛选与排序 MUST 可从可分享地址恢复且不含凭证。
  空库、空结果、加载中和加载失败 MUST 有可区分、可恢复的状态。**验收**：User Story 1 场景 1～6；AC-003。
- **FR-003（本轮）**：详情 MUST 展示功能简介、适用场景、使用方法、原文、版本或内容标识、作者、
  官方主页、开源地址和更新时间。站点说明、站内标签/备注与上游原文 MUST 分区；
  作者、官方主页、开源地址或更新日期缺失时 MUST 明确显示“未提供”，不得编造。原文未声明版本时
  MUST 展示当前内容的来源短修订或内容标识；若连内容身份也不可用，显示“未提供”并报告数据缺口，
  不得把声明版本等同于内容身份或编造 SemVer。原文 MUST 以可读形式展示代码块、
  表格、列表和有效附件相对链接；活动 HTML/脚本 MUST 不执行，外部地址 MUST 仅允许安全协议。
  未知 slug、原文不可用或加载失败 MUST 显示可返回/重试的明确状态。**验收**：User Story 2 场景 1～4；
  AC-004、AC-012。
- **FR-004（本轮切片）**：访客 MUST 能复制当前详情链接；列表存在查询、筛选或排序条件时 MUST 能分享并恢复
  包含这些条件的地址。详情分享地址 MUST 延续 `#/skill/<slug>` 身份；查询/筛选/排序地址 MUST 使用
  可恢复的可公开表示；所有分享地址 MUST NOT 包含凭证、管理信息或内部路径。
  复制成功 MUST 在真实成功后提示；失败 MUST 明确提示并提供手动复制方式，不得误报成功。
  既有旧链接、刷新和同 slug 内容更新 MUST 保持同一 Skill 身份并读取当前版本。
  US-001 已验收的原文复制、单文件/目录包下载和原件保真 MUST 继续可用，新界面不得以检索文本重建下载内容。
  **验收**：User Story 2 场景 5～6；AC-005；下载与原件部分沿用 US-001 的 AC-002 回归。
- **FR-010（本轮）**：界面 MUST 以搜索和分类为中心，卡片展示名称、一句话用途、标签、平台、版本及更新信息，
  详情首屏展示名称、简介、版本/内容标识、作者、来源及下载/复制/分享入口。
  MUST 支持明暗主题、简洁信息层级、清晰边框和有限动效；MUST NOT 使用粒子背景、自动播放视频或
  大面积霓虹干扰阅读。桌面端 MUST 采用筛选与结果分栏，移动端 MUST 使用可展开收起筛选和单列卡片；
  加载、空库、空结果、错误及窄屏代码块 MUST 有明确状态。搜索、筛选、详情、下载和分享 MUST 可用键盘完成，
  焦点可见，表单有标签，正文对比至少 4.5:1，减少动效偏好 MUST 生效。若保留管理入口，MUST 仅作为
  低权重外部链接；本轮 MUST NOT 新增管理员后台、访客登录或站内写入。**验收**：User Story 3 场景 1～4；
  AC-013、NFR-005。

### Key Entities

- **检索条件**：关键词、精准/模糊模式、标签、平台、来源类型、作者和排序；可被恢复到可分享地址。
- **结果卡片**：名称、一句话用途、标签、平台、版本及更新信息；只承载浏览所需信息，不堆满详情字段。
- **详情视图**：站点说明、站内标签/备注、上游原文、版本/内容标识、作者、官方/开源地址、更新时间和附件入口。
- **分享地址**：详情身份或查询/筛选/排序状态的可公开表示；不含凭证、管理信息或内部路径。
- **界面状态**：加载、就绪、空库、空结果、未找到、加载失败、复制失败等可区分状态及恢复动作。
