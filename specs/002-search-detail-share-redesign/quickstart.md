# Quickstart: US-002 检索、详情、分享与视觉改版

**Date**: 2026-11-05 | **Spec**: [spec.md](spec.md) | **Plan**: [plan.md](plan.md)

本指南只描述实施后的可执行验证步骤；字段和参数细节见
[data-model.md](data-model.md)、[search-ui.md](contracts/search-ui.md) 和
[detail-share.md](contracts/detail-share.md)。不包含实现代码、迁移脚本或生产发布步骤。

## 1. 前置条件

- Node 26.3.0、npm 11.16.0（以 `.node-version` 和 `package.json` 为准）。
- 干净 checkout；不执行 `skills/` 中的脚本或测试，不安装收录 Skill 的依赖。
- 已获授权的本地依赖与浏览器环境；生产发布和 Q-004 调度不在本故事内。

```bash
npm ci
npm run setup:security
npm run lint
npm run format:check
npm test
npm run build
npm run preview
```

预期：

- `npm run lint`、`npm run format:check`、`npm test` 退出 0（扫描器未安装时的环境限制要单独记录）。
- `npm run build` 返回 `status=built`，不修改原件或根 `assets/search-index.json`。
- `npm run preview` 只读提供 `http://localhost:8000/skill-gallery/`。

## 2. 检索与 URL 验证

使用隔离的 `tests/fixtures/search/` 样例或临时项目，至少覆盖：

1. 精准模式搜索名称中的 `debug`、双引号短语；模糊模式搜索 `debuging`；
   中文查询至少命中连续子串；记录实际结果，不以四项数据代替固定查询集。
2. 选择多个标签/平台、再叠加作者/来源：确认同维 OR、跨维 AND、结果去重。
3. 无关键词默认最近更新；有关键词默认相关度；显式名称/更新时间排序生效，并在查询/筛选变化后保持。
4. 复制/重新打开列表地址：查询、模式、筛选、排序、命中数和结果恢复；地址不含凭证。
5. 空库、空结果、加载失败分别显示不同状态；清除条件后恢复；不把加载失败显示为空库。
6. 修改 URL 中的未知参数、非法模式/排序、空筛选值：安全回退到可用状态，不崩溃。

记录：URL、输入条件、结果 slug 顺序、命中数和实际截图/DOM 证据。

## 3. 详情与分享验证

使用信息齐全和作者/版本缺失的隔离样例：

1. 详情显示功能简介、适用场景与使用方法、备注、原文、声明版本或内容标识、作者、
   官方/开源地址、更新时间和许可；缺失项显示“未提供”。
2. 声明版本缺失时显示内容标识（`digest` 短值）；声明版本存在时不把版本当作内容身份。
3. 原文中的代码块、表格、列表和相对附件可读；活动 HTML/脚本不执行；危险外链不变成可点击地址。
4. 旧 `#/skill/<slug>` 链接、刷新、同 slug 更新后仍打开同一 Skill；未知 slug 显示未找到并可返回。
5. 复制详情分享链接、复制列表地址；剪贴板拒绝时显示失败和手动复制值，不误报成功。
6. 查看原文、复制原文、下载单文件/目录包/附件：成功需要真实响应、大小和摘要校验；
   失败显示 `raw_unavailable`/`copy_failed`/`download_failed`。

记录：浏览器版本、地址、Skill slug、字段缺失状态、复制/下载结果和截图。

## 4. 响应式、主题与键盘验证

在 360、768、1440px 宽度分别执行：

1. 移动端单列卡片、筛选可展开/收起；桌面端筛选与结果分栏；正文外无横向溢出，代码块内部滚动。
2. 只用键盘完成搜索、模式切换、筛选、排序、打开详情、下载和复制分享链接；焦点可见，标签可读。
3. 切换浅色/深色主题；检查正文对比至少 4.5:1、焦点指示清晰、减少动效偏好生效；
   不使用自动播放视频、粒子背景或大面积霓虹。
4. 在 Chromium、Firefox、WebKit 记录版本和结果；未运行/失败的浏览器单独列为未验证。

记录：视口、主题、浏览器版本、键盘路径、焦点顺序、对比度和截图/操作记录。

## 5. 性能验证（AC-015）

使用 `tests/support/search-fixture.js` 生成 1,000 项、总正文 10 MiB 的隔离夹具，构建独立的 preview：

1. 记录设备、浏览器、Node/构建版本和查询集。
2. 数据加载完成后执行 50 次固定中英查询，测量“提交查询到结果可见”的时间；排除网络。
3. 计算 p95；候选通过线为 200ms。
4. 若不达标，记录瓶颈（搜索、筛选、渲染或输入处理），分析后再评估目标；不得悄悄改验收。

本故事不把 Node 微基准或四项真实数据的结果当作浏览器 p95。

  未运行项必须标为未运行，不能以规格、截图占位或任务勾选替代。

## 7. 停止条件

出现以下任一情况时停止并报告，不发布：

- 搜索/详情失败破坏 US-001 的复制、下载、旧链接或当前单版本；
- 分享地址含凭证、管理信息或内部路径；
- 活动内容被执行，或原文/附件被检索文本替代；
- 1,000 项性能无法测量或目标未达标且未完成分析；
- 浏览器/设备未运行却被写成通过。
