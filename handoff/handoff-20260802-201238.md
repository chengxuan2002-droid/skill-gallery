## 哪些坑不要再踩

1. **`skills/README.md` 会被构建脚本扫描** — 已修复，构建脚本现在会跳过 README.md。如果以后在 skills/ 里加其他非 skill 的 md 文件，记得同步更新构建脚本的过滤逻辑。

2. **Python http server 在沙箱里启动失败** — 因为 `nice(5) failed: operation not permitted`。本地正常环境没问题，不用管。

3. **详情页 markdown 渲染用的是纯文本 content** — 构建脚本的 `markdownToText` 函数会去掉格式标记。如果以后想要详情页显示完整的 markdown 格式（代码高亮、表格等），需要改成 fetch 原始 .md 文件。v1 用纯文本是为了简单和性能。

4. **git init 在沙箱里也会失败** — 因为 .git 目录操作需要 escalated 权限。用户本地直接 `git init` 没问题。

5. **frontmatter 解析是手写的** — 只支持简单的 YAML 格式（标量、数组、多行字符串用 |）。如果以后用到复杂嵌套 YAML，可能需要换用成熟的 YAML 解析库。目前的格式完全够用。
